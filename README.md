## 文件夹定位对比

| 文件夹名称                 | 主要职责             | 核心特性                                                                          |
| -------------------- | ------------------------ | ----------------------------------------------------------------------------- |
| `container`          | 提供自己实现的通用数据结构模板库   | 智能指针、容器（`vector`、`list`、`tree_map`、`tree_set` 等）、简单算法、仿函数、哈希、布隆过滤器等  |
| `log`                | 提供自己实现的可配置、并发、高性能日志库 | 双缓冲异步写入、时间类封装、暂存推送、文件/控制台输流的添加和删除                                     |
