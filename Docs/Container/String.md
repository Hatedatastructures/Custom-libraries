# String

`StandardCon::String` 是可修改的字节字符串。它自行管理字符缓冲区，提供长度、容量、子串、插入和大小写转换等接口；它不是 `std::string` 的别名。

## 缓冲区表示

对象保存缓冲区指针、逻辑长度和容量。`Size()` 与 `Capacity()` 都不包含结尾空字符；有缓冲区时，`MemberData[Size()]` 始终写入 `\0`。默认空字符串可用空指针表示。容量是当前缓冲区可存放的字符数，分配时另留一个字节保存终止符。

字符追加在容量不足时按几何策略增长：首次至少预留 2 个字符，之后通常翻倍；字符串或 C 字符串批量追加只确保足够容纳新内容。`Reserve(n)` 只增加容量、不改变长度，也不缩小容量；它返回缓冲区起始指针。`Resize(n, ch)` 改变逻辑长度，扩展区域填入 `ch`，默认填 `\0`，缩短时保留已分配容量。

```cpp
#include <Wan.hpp>

int main()
{
    StandardCon::String Text{"hello"};
    Text.PushBack('!');
    Text.Resize(8, '.');
    Text.Reserve(32); // Size() 仍为 8
    return 0;
}
```

## 操作与复杂度

| 操作 | 复杂度 | 说明 |
|---|---:|---|
| `Size`、`Capacity`、索引访问 | O(1) | `operator[]` 对越界索引会抛出 `CustomException::Fault`。 |
| 追加单个字符 | 均摊 O(1) | 容量不足时申请新缓冲区并复制已有内容，单次扩容 O(n)。 |
| 追加字符串或插入子串 | O(n+m) | `n` 为现有内容长度，`m` 为输入长度；必要时重新分配并移动/复制字符。 |
| `Reverse`、大小写转换 | O(n) | 逐字符处理；`Reverse` 返回新对象。 |

长度加法会检查溢出，超过可表示上限时抛出 `std::length_error`。字符追加和字符串追加都维护末尾 `\0`。自追加通过临时副本或重叠安全拷贝处理；传入指向本缓冲区的 C 字符串时也会先暂存输入。

## 字符串边界与失效

这是以 `\0` 结尾的字节字符串，不是任意二进制缓冲区。`PushBack('\0')` 可以在逻辑长度内插入 NUL 字节，但 `CStr()` 及以 C 字符串方式处理的外部 API 会在该字节处截断；逻辑 `Size()` 仍包含它。

缓冲区重新分配后，之前取得的 `CStr()` 指针、迭代器和字符引用失效。即使容量未变，插入、删除、反转或改长也可能改变原位置的字符含义。`Reserve` 在无需扩容时不更换缓冲区；容器不提供内部并发同步。
