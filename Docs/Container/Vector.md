# Vector

`StandardCon::Vector<T>` 是连续存储的动态数组。它为已构造元素分配连续内存，适合按索引访问和遍历；在头部插入或中间删除会移动后续元素。

## 存储与扩容

实现使用 `std::allocator<T>` 管理原始存储，并维护三个边界：缓冲区起点、已构造元素的尾后位置和容量尾后位置。只有 `[Begin(), Begin() + Size())` 中的对象已构造；预留容量不默认构造元素。迭代器是指向元素的原始指针。

首次扩容目标容量为 10，之后通常按两倍增长；若单次请求更大，则直接取满足请求的容量。容量只增不减，元素用分配器 traits 显式构造和销毁。

## 调整大小与常见复杂度

| 操作 | 语义与复杂度 |
|---|---|
| `Resize(n)` | 至少预留 `n` 个元素的空间，不改变 `Size()`；无需扩容时 O(1)，扩容时迁移现有元素，O(n)。这个接口相当于 reserve，不是改元素数量。 |
| `SizeAdjust(n, value)` | 改变元素数量；扩展时复制 `value` 初始化新元素，缩小时销毁尾部元素。工作量与新增或销毁元素数成正比；必要时扩容。 |
| `Find(i)`、`operator[](i)` | 按索引访问，O(1)；索引越界抛出 `CustomException::Fault`，并向 `std::cerr` 输出诊断。 |
| `PushBack`、`PopBack` | 尾部追加均摊 O(1)，触发扩容时 O(n)；尾部删除 O(1)。 |
| `PushFront`、`PopFront` | 需要移动其余元素，O(n)。 |
| `Erase(pos)` | 删除迭代器位置的元素并左移后续元素；若位置索引为 i，复杂度 O(n-i)。返回下一个元素的迭代器。 |

```cpp
#include <Wan.hpp>

int main()
{
    StandardCon::Vector<int> Values;
    Values.Resize(32);          // 预留容量，Size() 仍为 0
    Values.SizeAdjust(3, 7);    // 构造三个值为 7 的元素
    Values.PushBack(Values[0]); // 自引用追加
    return 0;
}
```

## 异常与类型要求

扩容先申请新存储，再构造新增元素并迁移旧元素；迁移使用 `std::move_if_noexcept`。非空向量中的元素必须可复制构造，或可不抛异常地移动构造；既不可复制又可能在移动构造时抛异常的类型，扩容会以 `std::logic_error` 拒绝。新存储构造失败时会销毁已构造部分并释放新存储。

无填充值的 `SizeAdjust(n)` 要求 `T` 可默认构造且可复制构造：当前实现先创建默认填充值，再经复制填充重载构造新增元素；带填充值的重载要求可复制构造。`Erase`、`PopFront` 和有剩余容量时的 `PushFront` 需要移动赋值。若这些原位移动赋值抛异常，已有元素值可能已部分改变，但元素对象仍保持构造状态。

追加或前置插入的实参若引用本向量中的元素，会先暂存该值以避免扩容时悬空引用。若用自引用右值且 `T` 的移动构造会抛异常，暂存过程本身可能使源元素处于 moved-from 状态。

## 迭代器与引用失效

- 扩容会更换存储区，使所有旧指针、引用和迭代器失效；`Resize` 未触发扩容时不失效。
- 尾部追加未扩容时，既有元素的指针和迭代器保持有效；头部插入和删除会改变受影响位置之后的元素对应关系。
- `Erase` 使删除位置及其后的迭代器失效；此前元素的迭代器保持有效。
- `SizeAdjust` 缩短时，仅被销毁的尾部元素引用失效；扩展时若发生扩容，则所有旧引用和迭代器失效。

容器不提供内部并发同步；并发读写须由调用方同步。
