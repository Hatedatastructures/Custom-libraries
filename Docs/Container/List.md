# List

`StandardCon::List<T>` 是循环双向链表，适合需要稳定节点地址、在已知位置频繁插入或删除的场景。它不提供连续存储，也不适合按索引随机访问。

## 内部结构

每个元素单独保存在节点中，节点基类维护前驱和后继指针。链表另有一个不保存元素的哨兵节点：空表时哨兵的前后指针都指向自己；非空时元素首尾与哨兵闭合成环。元素数单独缓存，因此 `Size()` 为 O(1)。

插入通过改接相邻两节点的链接完成；删除先摘除节点再销毁元素。已知迭代器位置时，这两种链接操作都是 O(1)，但每个新元素仍需分配节点。

```cpp
#include <Wan.hpp>

int main()
{
    StandardCon::List<int> Values{1, 3};
    auto Position = Values.Begin();
    ++Position;
    auto Added = Values.Insert(Position, 2); // 插入到 3 之前
    Values.Erase(Added);
    return 0;
}
```

## 操作与复杂度

| 操作 | 复杂度 | 说明 |
|---|---:|---|
| `Begin`、`End`、`Front`、`Back`、`Size` | O(1) | 迭代器和首尾值直接由哨兵链接取得。 |
| `PushFront`、`PushBack`、`PopFront`、`PopBack` | O(1) | 只改接首尾节点；空表弹出不执行操作。 |
| `Insert(position, value)`、`Erase(position)` | O(1) | 不含节点分配或元素构造/析构的成本；按索引查找位置仍需 O(n)。 |
| 遍历或按位置查找 | O(n) | 沿前驱/后继链接逐节点移动。 |

`Front()` 和 `Back()` 要求链表非空。对空链表执行 `PopFront()`/`PopBack()` 不改变状态。

## 迭代器、所有权与异常

迭代器保存当前节点和所属链表的哨兵指针；相等比较同时检查两者。`Insert`、`Erase` 收到未绑定或属于其他链表的迭代器时抛出 `std::invalid_argument`。尾后迭代器指向本链表的哨兵，可作为 `Insert` 的插入位置。

插入不会移动既有节点，因此既有节点的迭代器和引用保持有效；删除只使被删节点上的迭代器和引用失效。清空会使所有元素迭代器失效。移动和交换转移哨兵及其元素节点，原节点迭代器随节点转移到新所属链表；被移动对象会取得新的空哨兵。

链表自身没有线程同步。元素节点分开分配会带来额外内存和指针访问开销；需要随机访问或缓存局部性时应选连续容器。
